# 知識に照らして判断を見直す

利用者の現在の目的・制約・基準に照らして、計画・判断・行動を評価し、判断と推奨理由を返す。依頼されていない改善や実行へ範囲を広げない。

- 提示された計画・記録で評価できれば、その情報で進める。記事が必要な場合だけ [article-explore](../article-explore/SKILL.md)、意味や矛盾の検討が必要な場合だけ [knowledge-deepen](../knowledge-deepen/SKILL.md) を参照する。単独でも完了できる。
- 選択肢の適合と懸念を比較し、条件が十分なら第一候補と推奨理由を示す。記録から推論した効果の見通しと、現在の目的に基づく選択基準を区別する。反例、記録の偏り、時期の違いを評価に含める。
- 過去の価値観と現在の目的が衝突する場合は、過去を現在の基準と決めつけない。利用者の訂正・現在の意向を優先して評価を見直す。

記事を使う場合は原文とURL・取得時点を確認する。同期・オンライン編集・記憶保存の権限と手順はリポジトリのAGENTS.mdと該当Skillに従う。

回答方針・共通循環・記憶操作はAGENTS.md・READMEの規約に従う。適用未確認・矛盾・結果待ちを区別し、判断を変える材料を補いながら評価できる部分は進める。提案後の結果を仮定で埋めない。
