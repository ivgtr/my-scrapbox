# 知識の意味を深める

利用者が理解したいことに沿って、記録間の関係・矛盾と説明の候補を考察の中心にする。自己理解とテーマ理解を固定の別手順に分けない。

- 提示された文章や対話で足りれば、その情報で進める。記事が必要な場合だけ [article-explore](../article-explore/SKILL.md) を参照し、探索と解釈を必要に応じて行き来する。
- プロファイリングでは記事別の紹介に留まらず、記録を横断した傾向と、それを説明する仮説を示す。反例、記録の偏り、時期や状況の違い、競合する説明を検討し、固定の人格像や現在の意向と決めつけない。
- 予測を求められた場合は、記録から推論した見通しと、その成立条件・不確実性を示す。
- 利用者が解釈を否定したら、訂正に沿って仮説を見直す。過去の記録から現在の意向を上書きしない。
- 計画や判断の評価へ進む依頼なら [knowledge-review](../knowledge-review/SKILL.md) を参照する。深掘りだけでも完了でき、回答形式は依頼に合わせる。

記事を使う場合は原文とURL・取得時点を確認する。同期・オンライン編集・記憶保存の権限と手順はリポジトリのAGENTS.mdと該当Skillに従う。

回答方針・共通循環・記憶操作はAGENTS.md・READMEの規約に従う。既存の理解は適用条件・例外・根拠の状態を確かめて再利用する。
